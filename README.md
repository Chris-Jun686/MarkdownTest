### 2. 人才获取渠道

- **LinkedIn**：适合寻找**资深PE、本地化项目经理（PM）** 等关键岗位。搜索关键词如“Game Localization”、“Localization Producer”、“LQA Specialist”加上目标语言。
- **专业社群与论坛**：如ProZ.com、Reddit的r/gamedev、r/TranslationStudies等，适合接触**自由译者**社群。日本的本地化人才常活跃于特定行业社群。
- **自由职业平台**：如Upwork、Fiverr，适合**短期、小规模**的LQA测试任务，成本灵活，能快速验证人才能力。
- **转介网络**：通过现有核心专家推荐。数据显示，游戏本地化从业者多依赖**非正式学习**和**社区网络**进入行业，转介是获取高质量人才最有效的方式。
- **招聘网站与猎头**：国内如猎聘上有大量游戏本地化岗位，可发布招聘信息筛选候选人。

### 3. 人才保留与关系管理（Optional）

本地化人才稀缺，尤其是复合型专家。以下是保留核心人才的关键策略：

- **长期合作承诺**：为核心PE/LQA提供**长期合同**或**优先排期权**，降低其对项目不稳定的焦虑。
- **职业成长支持**：提供行业趋势分享、新工具培训（如AI辅助翻译）、参加行业会议的机会。
- **关系维护**：即使非合作期也保持联系，定期发送项目动态，邀请参与线上讨论。
- **质量与成本平衡**：参考维塔士在游戏开发领域“**在上海建团队，培养人才、沉淀技术**”的模式——虽然成本高，但换来的是“**最贵的不是办公室，是那个凌晨三点还能精准指出动画权重偏差的动画师**”。这提示你的资源池也需要从“降低成本”思维向“构建生态”思维转变，留住能解决关键问题的专家。
