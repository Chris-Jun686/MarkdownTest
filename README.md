### 1. 初期核心目标Pool规模

| 语言 | 策略定位 | PE人数调整逻辑 | LQA人数调整逻辑 | 最终核心Pool |
| :--- | :--- | :--- | :--- | :--- |
| **JP** | **Quality-first** | 供应紧俏，需优先锁定 **2人**（1做主力，1做质检复核） | 单价高（$22-30/hr），宁缺毋滥，**1人** 资深 | **PE 2 + LQA 1** |
| **KR** | **Scale-first** | 产能要求高，需 **2人** 应对突发流量 | 单价适中（$20-28/hr），**1人** 全职 + 外包备选 | **PE 2 + LQA 1** |
| **RU** | **Cost-first** | 严格控制成本（$0.035-0.055/字），**1人** 核心 + 大量自由译者 | 单价最低（$16-22/hr），**1人** 兼职/外包 | **PE 1 + LQA 1 (外包)** |

### 2. 人才获取渠道

- **LinkedIn**：适合寻找**资深PE、本地化项目经理（PM）** 等关键岗位。搜索关键词如“Game Localization”、“Localization Producer”、“LQA Specialist”加上目标语言。
- **专业社群与论坛**：如ProZ.com、Reddit等，适合接触**自由译者**社群。日本的本地化人才常活跃于特定行业社群。
- **自由职业平台**：如Upwork、Fiverr，适合**短期、小规模**的LQA测试任务，成本灵活，能快速验证人才能力。
- **转介网络**：通过现有成员推荐转介。游戏本地化从业者多依赖**非正式学习**和**社区网络**进入行业，**高校语言专家**也可考虑
- **招聘网站与猎头**：国内如猎聘上有大量游戏本地化岗位，可发布招聘信息筛选候选人。

### 3. 人才保留与关系管理

- **定期重新评估**：每半年或一年做一次小型测试或项目后评估。
- **持续反馈**：PE/LQA 项目完成后，内部 reviewer 给出简短反馈。
- **更新可用性**：至少每季度确认一次PE与LQA人员可用状态。
- **长期合作承诺**：为核心PE/LQA提供**长期合同**或**优先排期权**，降低项目不稳定可能造成的焦虑。
- **职业成长支持**：提供行业趋势分享、新工具培训（如Orbit8 Agent参与的辅助翻译）、参加行业会议的机会。
- **淘汰低效资源**：质量连续不达标或沟通成本过高的资源要降级或移除。
- **知识沉淀**：把项目style guide、术语库、常见错误案例分享给pool，降低培训成本。
