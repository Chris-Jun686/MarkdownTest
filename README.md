# 虚幻引擎本地化系统工作指南

本文档旨在规范开发团队与 Orbit8 团队的虚幻引擎（UE）本地化协作流程，涵盖文本导出、文件交付、导入及校验方法。

## 1. 什么是虚幻引擎的本地化系统？

引擎内置的多语言翻译框架，可根据玩家语言设置自动切换文本。
**核心规范：必须使用 FText**。普通字符串（`FString`）无法被引擎收集和本地化。

## 2. 可本地化的文本格式

* **C++**：使用 `NSLOCTEXT` 宏，例如 `NSLOCTEXT("UI_MainMenu", "Btn_Start", "开始游戏");`
* **蓝图**：使用 `Text` 类型变量，引擎会自动收集其默认内容。

## 3. 本地化资产保存路径与文件含义

文件默认保存在 `Content/Localization/<目标名称>/` 目录下。

> **交接重点**：**只交付 `.po` 文件**给 Orbit8 团队。**严禁交付** `.archive` 或 `.locres` 文件（翻译团队无法解析这些内部格式）。

## 4. 如何导出需要本地化的文本

1. 打开：**工具 -> 本地化控制板 (Localization Dashboard)**。
2. 配置搜索范围：
* **C++**：勾选“从文本文件收集”，填写源码目录。
* **蓝图**：勾选“从包收集”，填写内容浏览器目录。


3. 点击 **收集文本**。
4. 在目标语种（如 `zh-Hans`）所在行，点击右侧的 **“导出此语言的翻译”**。
5. 将生成的 `.po` 文件发给 Orbit8 团队。

## 5. 如何导入翻译后的文本文件

1. **存放文件**：将 Orbit8 返回的 `.po` 文件放回原语言目录（如 `.../zh-Hans/Game.po`），勿随意改名或更改路径。
2. **执行导入**：在本地化控制板中，找到目标语种行，点击右侧的 **“导入此语言的翻译”**，选择翻译好的 `.po` 文件。
*⚠️ 错误做法：切勿点击控制板顶端的“导入文本”按钮。*
3. **编译文本**：导入后，**务必点击“编译文本”**，方可在游戏中生效。

## 6. 预期效果（如何验证）

依次点击：**编辑 -> 编辑器偏好设置 -> 区域和语言 -> 预览游戏语言**。切换至目标语种，即可在编辑器中实时预览翻译效果。

---

## 7. 常见问题排查（FAQ）

**Q1：点击“收集文本”未收集到内容？**

* **排查**：检查收集路径是否正确；确认“项目设置 -> 本地化”中的目标（Target）是否已正确配置注册。

**Q2：导入 .po 文件提示找不到文件，或点击后无反应？**

* **排查**：大概率误点了控制板最上方的“导入”按钮。必须点击**目标语种所在行右侧**的专属导入按钮。

**Q3：导入后，预览依然显示未翻译（显示英文或Key值）？**

* **排查**：
1. 确认导入后是否已点击 **“编译文本”**。
2. 检查 `.po` 文件内部标头的语言代码是否与引擎一致（如 `.po` 里是 `zh_CN`，而引擎配置为 `zh-Hans` 会导致读取失败）。
3. 重启虚幻引擎，刷新本地化缓存。



**Q4：Orbit8 团队反馈文件无法打开或翻译？**

* **排查**：开发误发了 `.archive` 或 `.locres` 文件。请重新导出，**仅交付 `.po` 文件**。
